WHAT YOU CAN DO

从具体的使用场景开始。

让角色待在桌面上

通过原生 Windows 客户端呈现 Live2D 角色，使用文字和语音交流。

把对话交给 Agent

复用 AgentStrata 的上下文、模型与工具能力；客户端负责角色呈现和语音播放。

在工作台继续改进

已有桌宠可接入 Studio，沿现有开发与验收流程改进。开发环境与日常运行环境分别准备。

GET STARTED

如何开始使用

  1. 准备桌面客户端当前从源码构建 Windows 11 x64 安装包；已有安装包的开发者可按使用指南启动。
  2. 配置模型和角色按客户端指南连接模型，选择可使用的角色与语音资源。模型和音源各自的授权仍需满足。
  3. 开始对话在桌面角色界面用文字或语音交流。需要开发改进时，再连接 Studio。

当前交付状态

当前是开发者预览，尚无公开 Release 安装包。原生 Windows 运行不要求 WSL；开发侧 Harness / Eval 使用 Linux。Windows 目前支持新安装和同版本修复，不承诺更新、回滚或完整角色生成工作台。

本机应用需要电脑保持运行和联网。本站不提供托管聊天，也不收集 API Key 或机器人 Secret。
