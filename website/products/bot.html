描述机器人的用途，核对 Agent 生成的提案，再确认应用。已有能力无需每次重新开发。

连接 QQ 官方机器人

填写自己的 AppID 和 AppSecret，使用官方 WebSocket 渠道。首版支持群内 @ 和单聊的被动文本回复。

看清应用是否可用

配置检查、进程状态、渠道连接与真实消息往返分别判断；可以检查、启动和停止应用。

GET STARTED

如何开始使用

  1. 准备 Studio 工作台当前 Windows 11 x64 + WSL2，从源码构建。准备有效模型连接，不需先登录开发账号才能配置标准应用。
  2. 创建你的 QQ 助手在 Studio 选择 QQ 产品入口，说明用途并确认配置。QQ 平台账号、机器人资格和测试范围需由你准备。
  3. 连接并真实试聊Secret 仅填入专用凭据表单。检查、启动后，在允许的 QQ 测试范围发送消息并确认回复。

当前交付状态

当前是源码 MVP，尚无公开 Release 安装包或托管服务。真实 QQ 与模型往返需在你的平台权限范围内验收；不包含媒体、主动消息、Webhook 或云托管。通用代码开发、Eval 与 Harness 的工作台闭环仍在完善。

本机应用需要电脑保持运行和联网。本站不提供托管聊天，也不收集 API Key 或机器人 Secret。
