做一个 Live2D 桌宠。

从当前桌宠开始

本片使用「连接 Live2D 桌宠」入口，工作台核对本机安装及配套载荷，从该版本的公开源码继续开发。找不到唯一匹配项时，可以选择已安装的程序。试用副本单独安装，使用独立配置和数据。具体操作见桌面工作台指南。

尚未安装桌宠时，先按Live2D 安装指南准备原生客户端、运行依赖和自己的模型连接。开发工作台面向 Windows 11 x64，使用 WSL2；桌宠本身在 Windows 原生运行。图形资产制作与声音训练各有独立流程。本例训练音源由另行配置的本地服务提供，该服务运行在 WSL 中。

安装包包含什么

包含桌宠窗口、输入与播放功能、应用自己的助手配置和运行代码、对应源码、依赖锁文件、许可及构建选定的上游资源。私人角色、语音模型、模型密钥和聊天记录不会自动随包交付。接收方首次运行需要联网准备依赖，并设置自己的模型连接与所需的声音服务。

Linux / WSL 还支持从已验收任务导出 application.json、source/ 和 install.sh，保留 Console、检查与部署工具。安装后配置连接并启动服务。它与 Windows 桌宠安装包是两种交付方式，详见源码交付指南。

这次实际完成了什么

工作台采用当前 main 界面，在独立录制工作区实际连接本机桌宠，完成版本核对和公开源码导入。视频将资源校验的等待剪短。随后填写的需求没有发送，没有启动新一轮开发、验收或安装包构建；这些部分以操作说明呈现。

开头的声音与口型来自 2026 年 11 月 5 日原生客户端的实际播放，保留原速。客户端检验章节使用同次历史画面配旁白，列出应实际检查的项目。Console、Harness、Eval 和结尾角色保留各自来源标注。当前桌宠及其私人配置保持原样。

声音沿用用户训练并授权的音源。角色、第三方客户端、SDK 和模型保留各自许可；本视频不提供角色或语音权重下载。
