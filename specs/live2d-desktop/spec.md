# Windows Live2D 桌面入口

## Summary

Windows Electron 壳复用 WSL 交互页面与角色工作台。角色库、生成任务、凭据和 Agent
继续由现有插件管理；不增加 AgentRuntime、Gateway 或角色数据格式。

## Design

桌面主进程通过固定参数的 `wsl.exe --distribution … --exec …` 调用插件 CLI，
读取受管安装记录中的回环地址。设置页只保存发行版、可执行文件、插件目录和窗口偏好。
不接受渲染进程提交命令、路径或 URL；网页只能请求窗口操作、打开管理页、应用角色 ID/
版本和撤回备份 ID。设置页拥有独立调用权限，后端页面不能改变执行配置。

单实例、单个交互 BrowserWindow 保持连接，切换透明桌宠模式不重新加载页面。管理页
使用另一个窗口。HTTP 页面保留原 Origin 边界，Node 关闭，启用沙箱和上下文隔离。
主进程校验窗口、主 frame、精确来源、IPC 参数；禁用任意导航、弹窗和屏幕采集。
语音仅显式开启，隐藏窗口停止麦克风；退出桌面不停止后台和生成任务。

角色操作先向交互窗口确认空闲并冻结输入，再停止交互插件、执行既有应用事务、启动并
就绪后重新加载。新配置启动失败则停止失败实例、恢复事务备份、启动原配置。恢复失败
保持失败状态并展示备份 ID。管理页在桌面内走此编排，普通浏览器维持停机后应用流程。
生成器始终独立运行；权限、会话、记忆和模型连接不随角色切换迁移。

发布仅封装桌面代码、Electron 与许可材料，不嵌入角色、目录、后台配置或聊天数据。
使用 Windows 原生构建目录和锁文件，交付安装包、便携包及匹配源码；不自动更新或发布。
首次资料切换先停止预览写入、完整备份，再通过既有恢复接口导入，任务按摘要复制；
冲突停止，不覆盖，保留预览目录以便恢复入口。

## Acceptance

- WSL 未安装、命令错误、插件缺失、端口冲突和启动失败均显示可操作状态。
- 单实例和模式切换不建立第二套交互连接；托盘可撤销穿透和恢复窗口。
- 角色应用、启动失败和回滚失败结果准确，生成任务和持久资料不被清理。
- 非授权来源、子 frame、任意命令/路径参数及摄像头/屏幕权限被拒绝。
- 自动化替身、Windows 窗口实测、真实 LLM/TTS 和实体麦克风证据分别报告。

## Verification

执行桌面单测、受控页面 Electron smoke、Windows x64 构建，插件定向测试、固定上游
兼容检查、生成器独立安装检查和仓库 full。真实模型复用本地角色，不再次上传参考图。
不终止开发 WSL 模拟冷启动；无法安全测试的硬件或系统情形明确列为人工验收项。
