# 独立 Live2D 生成插件

## Summary

增加可选 `live2d-generator` 插件，将提示词、角色资料、参考图片或分层素材转换为供
Open-LLM-VTuber 加载的模型包。生成是一项资产制作任务，不进入 AgentRuntime 对话链。
插件有独立 Python 包、配置、私有工作目录、本地工作台和 CLI；主程序仅登记插件。

## Design

遵守[四层运行时](../runtime-four-layer-definition/spec.md)、
[六层依赖](../domain-layered-dependencies/spec.md)和
[插件生命周期](../external-software-plugins/spec.md)。不增加模型路由、工具注册体系或
长期队列。独立 Images 服务生成立绘，See-through 兼容 HTTP 服务或明确配置的 Gradio
Space 拆层，固定版本 image2live2d 在 CPU 上绑定并导出真实 `.moc3`。也可直接输入 PSD
或语义命名的 PNG 图层 ZIP。图片默认直接拆层，只有显式选择重绘才调用 image edits。

Types 定义请求、错误和 provider 端口；Config 读取固定配置与凭据环境变量名；Repo
负责私有任务记录、受限解压、引用校验和完整包发布；Service 通过端口驱动图像、拆层和
绑定；Runtime 装配具体 provider 和一个受时间限制的工作进程；UI 仅映射 HTTP/CLI。
六层允许直接依赖左侧层，不增加空壳。生成插件不导入 Agent、Gateway 或 VTuber runtime。

工作台只监听回环并验证 Host/Origin，同源页面提供随机会话令牌，API 在访问任务正文
及副作用前验证令牌。不开放来自任务的服务 URL、命令、文件路径或上传脚本执行。
图片、ZIP、PSD 和模型引用在解码/展开前检查实际资源边界。服务凭据只读取环境，不写
入任务、导出包、浏览器或公开错误；远端错误正文不向用户透传。

每个数据目录只有一个活动生成器和一个工作进程。状态阶段落盘，提交不自动重试；取消
终止本地工作进程，不能保证远端已提交推理停止。超时和重启中断均明确失败。完成必须
有有效 MOC3 头、可解析 model3、纹理和完整相对引用；文件完整性不等于 SDK 加载验证。
自动绑定输出是可精修初稿，不能用静态 PNG 或缺少 moc 的 JSON 包替代成功。

VTuber 将原始模型目录和字典初始化到持久数据目录，上游固定补丁通过专用环境变量读取
该目录。现有初始角色仍有效。生成器提供显式 install/restore 命令，仅在同用户的受管
客户端停止时修改模型字典、角色名和动作白名单；不修改 BotSpec 身份、提示词或模型连接。
导入持有现有安装锁，写前备份；普通失败自动恢复，崩溃留下 journal 并阻止客户端启动。
restore 核对备份摘要及当前配置，拒绝覆盖后续编辑，保留导入资产。

独立 wheel 携带安装资源和自有许可，上游程序、SDK、权重及模型不纳入源码或 wheel。
第三方运行依赖固定版本与 SHA256。示例只分发角色描述和用户提供的来源链接，实际图像
和生成包保留在私有产物目录。可用性、自动绑定质量和第三方使用条款分别说明。

## Acceptance

- 提示词、资料、图片和分层输入共享可观察的生成流程；缺失服务或输出明确失败。
- 包含真实模型、动作、表情和证据清单，可由既有客户端加载和驱动。
- 取消、超时、重启与并发提交可判断；越界路径、恶意压缩包和不完整模型不能发布。
- 显式导入与恢复保护原有配置和用户后续修改，凭据不进入请求与产物。
- 主程序无需安装生成依赖；独立插件安装、发行校验及相关回归通过。

## Verification

定向测试覆盖请求、provider 协议、任务状态、资源边界、产物完整性和导入回滚。
实际样例经过图像生成、拆层与绑定后单独检查 Cubism 加载、网格参数变化和浏览器。
执行插件发行检查和项目 full 门禁；真实图像服务、拆层服务、SDK、替身接口与 Agent
对话分别记录证据，不能将文件校验或测试替身描述为真实对话验收。
