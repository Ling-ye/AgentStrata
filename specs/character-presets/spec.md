# 持久角色库与私有预设分发

## Summary

Live2D 生成插件维护稳定角色 ID、不可变版本、完整工程备份和精选预设包。
本地创作资料独立于生成任务与客户端运行数据；远端目录和模型按需认证下载。

## Design

遵守[四层运行时](../runtime-four-layer-definition/spec.md)、
[六层源码依赖](../domain-layered-dependencies/spec.md)和
[生成插件](../live2d-generation/spec.md)边界，不新增 AgentRuntime 接口。
Types 定义资料契约；Repo 负责角色、版本、摘要及目录事务；Service 提供保存、
导入、导出、备份和预设用例；Runtime 装配 GitHub 下载端口；CLI/HTTP 仅调用公开入口。

角色在生成插件持久数据目录 characters/ 中保存 UUID、草稿与递增版本。版本自带
模型及白名单创作资料，不引用任务目录；新版本不覆盖旧版。原始输入在工作进程启动前
写入角色草稿来源目录，生成失败也可备份；保存失败时不提交远端推理。下载角色为只读来源，
修改通过新 ID 的本地副本进行。备份为带完整摘要的目录，恢复先检查全部冲突。

成品预设采用 agentstrata-character-preset-v1，封装现有模型 ZIP、预览、人设及
Edge TTS 音色。成品导出不包含参考原稿、任务配置、日志、凭据、对话或记忆。
应用沿用客户端停机锁、备份和恢复 journal，在同一事务中更新模型、人设和声音；
恢复拒绝覆盖后续编辑。Bot identity/style 不提升到宿主权限，不写运行时人格与记忆。

私有仓库坐标与 token 仅由本机环境配置。GitHub API 认证只发送给 api.github.com，
资产重定向不携带认证头；缓存不保存临时下载 URL。目录只含版本、摘要、资产标识，
客户端下载暂存校验后提交。无凭据和无权限明确报告，离线已缓存资料仍可读取。
私有目录、缩略图及模型不进入公开源码或 wheel。维护者显式导出发布资料并更新目录，
生成任务不自动上传。既有任务及模型通过显式收录，不迁移或删除原始数据。

## Acceptance

- 同角色多版本可保存、预览、应用、撤回；任务清理不影响持久角色。
- 工程与整库备份可校验恢复，冲突及损坏不会覆盖当前数据。
- 预设只包含声明资料，下载异常、恶意归档及摘要不一致不能发布到本地库。
- 模型、人设、声音共同应用或回滚；权限、连接、会话和记忆归属保持不变。
- 私有目录认证、缓存、按需更新和凭据隔离有明确结果。

## Verification

定向覆盖存储、版本、备份、预设边界、HTTP/CLI、私有下载与配置回滚，执行插件
发行/兼容检查和项目 full 门禁。真实客户端模型、动作、TTS 与 LLM 对话分别记录；
替身测试及文件完整性检查不等于真实服务或 Cubism SDK 验收。
