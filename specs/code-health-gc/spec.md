# 代码治理与持续清理

## Summary

Console 提供独立的「代码治理」入口：冻结当前工作区，执行确定性检查和 Codex 只读巡检，
自动为有证据的问题生成一个小范围候选，验证后交由操作者提交。测试全绿也允许发现重复实现、
无效分支及文档漂移；不把代码卫生问题伪装成失败的机器人任务或测评 Case。
机制参考 OpenAI 于 2026-02-11 发布的《Harness engineering》中的仓库原则与持续小范围清理；
本项目的执行、验收和权限以本规格为准。

## Design

### 一套任务设施，两条工作流

遵循[四层运行时基线](../runtime-four-layer-definition/spec.md)。治理位于消息链之外；
Console 通过 Harness 公开控制入口发起任务和查询结果，Harness 拥有任务、生命周期与证据。
治理和 Case 修复共用 SQLite、按需 systemd worker、维护锁、取消、公开执行进度、归档及补丁下载。
worker 按明确的来源 kind 分派到治理或原有修复流程，不引入通用工作流引擎或第二套数据库。

新增来源 `code_health`，保存在已有任务 payload 中，不迁移或改写历史任务。原有修复入口、
复现规则、提交授权不变。治理 API 不接受提交开关、宿主路径或任意命令。
历史接口增加任务类型筛选；治理页复用现有详情、进度和取消接口。

`GET /api/harness/code-health/config` 返回范围、原则与执行默认值；
`POST /api/harness/code-health/tasks` 接收 scope、request_id 和模型执行参数。
历史使用 `GET /api/harness/tasks?kind=code_health`，详情/进度/取消/补丁继续使用原任务接口。
`GET /api/harness/tasks/{id}/check-log` 只接受该任务登记的日志 reference。

### 黄金原则与证据

规则分别约束依赖边界、代码卫生、共享实现、数据边界、过时实现和文档事实。
规则引用现有架构与领域契约；架构检查、Ruff、SDD 检查仍由各自检查器负责。
Codex 只读巡检补充语义问题，记录位置、原因、代码证据和建议；模型声称阅读的文件仅作为
巡检覆盖说明，不能冒充全仓验证。相似文本不证明语义等价，没有静态引用不证明代码可删除。
动态注册、公开接口、授权变化或旧数据兼容影响不明时列为待判断，其他可处理问题继续执行。

### 源码与候选

启动时记录 HEAD 和当前工作区源码摘要，包含未忽略的新源码与未提交修改，排除私有数据、
凭据和构建产物。冻结过程中漂移则终止，不构造混合快照。运行代码也从该快照装配。
任务专属 worktree 覆盖为冻结源码；候选补丁和失败恢复均以冻结内容为基准，而非 HEAD。
原工作区、暂存区和分支不变。治理不暂存、提交、推送、创建 PR、合并或部署。
打包投影所需索引与 Git 对象仅在私有验证目录生成，不改写仓库索引；未暂存源码也接受验证。

扫描时源码只读；修复阶段仅开放当前范围内产品源码、普通文档和前端源码。
治理/Harness 控制、测试、评分、检查器、配置、权限执行与凭据设施保持只读，模型不能
修改规则或豁免来制造通过。已有 Case 修复的写入范围不随治理扩大。

### 执行与验收

流程为：快照 → 确定性扫描 → 只读语义巡检 → 小范围候选 → 固定检查 → 独立只读审查 → 交付。
模型、推理强度、轮数和总期限沿用 Harness 执行参数，模型由治理入口指定，不绑定机器人。
单任务时间预算贯穿阶段；同一请求幂等，已取消或中断的治理需重新启动并获得新快照。
没有可处理问题是有效结果；剩余待判断项和未覆盖区域照实保留，不伪造熵分数。

验收绑定候选摘要、目标发现和冻结规则。确定性问题需重新检查，语义变化需结合真实源码、
补丁与回归证据审查。源码或前端发生跨域、架构变化时执行 full；局部清理使用 fast。
基线与候选使用同一检查范围，收集完整结果。Ruff/架构/SDD 既有问题由前后结构化发现比较，
pytest 既有失败按 node id 比较；目标必须消失，新的问题、未知检查失败或不完整证据仍阻断。
保留的既有失败单独展示，不改写门禁的失败结果。检查器、环境或模型错误明确记为失败/受阻，
不能标记为清理成功。只有实际验证通过的候选才能显示「已验证，待人工提交」。
共享任务与 artifact 权限及同源写入边界保持。

## Acceptance

- Console 一键发起，显示阶段、公开执行进度、分页历史、问题、补丁和验证记录。
- 工作区原有修改、新文件、删除及可执行位进入同一快照；补丁仅含本次清理差异。
- 全绿代码仍可进行语义巡检；无问题和待判断结果可正常展示。
- 不能修改保护文件，不能自行提交，候选或证据漂移不能获得成功状态。
- 重复请求、取消、调度失败、检查失败、模型失败及 Console 重启状态准确。
- 原有失败 Case 与机器人任务修复回归通过；不扩大其权限或触发额外模型评测。
