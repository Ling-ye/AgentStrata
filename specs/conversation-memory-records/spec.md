# 会话长期记忆条目与召回

## Summary

长期记忆按可信群或私聊身份存放为受保护的条目。常驻上下文只包含有界摘要，
其余条目按当前问题检索；所有记忆始终是不可信历史数据，不能授予权限。

## Design

身份、准入和作用域选择在记忆读写之前完成。每个当前群或私聊对象有独立的受保护
SQLite 条目库；模型和工具参数不能选择目标身份、路径或作用域。条目记录正文、类别、
来源 actor/turn、显式或自动来源、时间、版本和生效状态。单条操作使用条目 ID 和版本，
清空操作只接受明确的整份清空意图。受保护目录、数据库文件与锁均须验证 owner、
权限、类型和链接；并发写入使用固定锁和事务。

准入成员可以读取与追加当前作用域记忆；Owner 可以更正、删除单条或清空当前作用域。
普通成员的主动删除请求不能通过自动提炼绕过。可信用户发言可以自动形成当前作用域
候选；自动流程只从原文提炼有证据的稳定信息，排除秘密、群内个人隐私、指令性内容、
模型回复和工具输出。明确的新证据可使旧条目退出有效召回，来源关系仍可审查。
自动流程失败不阻断回复，也不能冒充持久化回执。

常驻偏好／决定及按当前问题检索的条目分别有界；中文短词、精确短语和关键词由本地
检索处理。PromptPlan 继续把它们标为 `untrusted_data`。显式持久化声称必须匹配
操作、可信作用域、条目 ID、版本及内容摘要，不能只匹配工具名。

旧 `MEMORY.md` 在停机并取得独占状态后归档并校验哈希，不导入新库，运行时不回退读取。
切换失败必须保留原件和归档证据。当前无效的 BotSpec 记忆 provider、namespace 和 schema
配置随新契约删除；`memory.chat` 工具包仍控制是否暴露记忆工具。

## Acceptance

- 否定句和单条忘记不触发整份清空；回执必须匹配实际变更。
- 群／私聊隔离、Owner 删除权限、自动来源、更新失效和重启恢复可核验。
- 中文两字查询可命中；每轮注入有界且不会把记忆提升为宿主规则。
- 自动提炼超时、重复处理或不可用时正常回复，状态如实呈现。
- 旧记忆归档后新库从空状态开始；真实模型与 QQ 验收独立记录。
