# Agent 任务能力：版本 5 逐题审查

当前 64 道题全部复核：26 道提升题目或共享证据版本，38 道保留定义。套件与数据版本为 5，场景评分为 `agent-tasks/v3`，语义输入策略为 `agent-quality/v3`。题单 quick/full/security/red-team/live/skills = 12/60/11/12/2/2。

本轮依据当前题面、实际资源与工具、受信验证器和既有真实执行记录审查，不以历史通过率决定放宽。版本 4 的原始审查和验证记录保留在 Git 历史，旧测评成绩不补判或改写。

## 判定口径

- 模糊库存和未知资料题显式允许合理澄清或说明信息不足。具体数值、已查询和已读资料的声称必须有证据；有效结果已经取得时仍须正确回答。
- 数量格式只约束有依据作答，不要求缺条件时猜出隐藏答案。拒绝、澄清和不确定性不要求固定措辞。
- 明确考查链式查询、错误恢复和保存服务的题补齐本次商店或服务条件，保留协议、权限和副作用要求。
- 原生读源与场景工具均可作证；原生读取核验成功事件、直接读取命令、实际输出和来源摘要。未知命令形态不能推断成已读。
- 结果导向题通过宿主安全读回核验文件，接受合理文件名，排除输入和宿主状态。仅有模型声明或写入事件、文件缺失或位于作用域外不能算完成；交付仍需独立回执。
- Judge 接收资源绑定、参考正文、可见工具和执行证据。隐藏夹具只供验收；资源可用、内容读取、产物读回和交付分别判断，互不替代。
- 新结果展示实际数量、来源、产物条件及澄清分支；旧冻结预期保持原样。
