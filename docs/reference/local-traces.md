# 本地执行归档

理解归档来源、作用域和读取边界；操作入口见 [诊断指南](../guides/debugging.md)。

AgentStrata 使用 DeepEval 4.2.2 的原生 trace/span 数据类型，在本地保存机器人 run、
Evaluation Trial 和 Harness 编程调用的执行记录。运行中的进度继续由现有机制提供；
执行单元结束后，在对应详情页按需查看归档。AI Harness 在流程步骤内展示关联的完整执行正文，
命令使用独立日志入口；展示与实时步骤语义见[修复流程记录](harness.md#修复流程记录)。

## 读取内容

调用树保存模型、工具、Agent、日志和运行阶段。展开步骤后按需读取输入输出、模型实际
上下文、工具完整结果及发送给模型的投影。正文较长时页面先显示预览，可继续展开全文。
「部分采集」、未完成步骤和 provider 内部状态不可见分别展示，不能将其解释为成功。
归档本身不调用模型或判分，也不上传数据。DeepEval 的自动采集、云端 offline_evals
入口和全局 trace manager 不参与本地记录。

## 存储与保留

每份归档由 `trace.json` 与 `artifacts/<sha256>.json` 构成。上下文及大正文分块保存，
相同正文在同一记录内复用；metadata.agentstrata 保存所属执行、覆盖、版本及引用清单。
索引和正文都在首次写盘前脱敏；引用只能在所属任务内解析并校验内容摘要。

Gateway 放在其私有观测根的 traces 目录，Evaluation 放在各自记录目录的 traces 中，
Harness 放在任务私有目录。读取通过各自服务的公开查询接口，Console 不接触数据库表或
客户端提供的文件路径。普通正文自归档完成起保留 30 天，摘要继续可读；宿主维护时清理
过期正文。已冻结的 Harness 来源及修复阶段记录不自动过期，随任务显式删除。

归档在终态原子发布，可捕获异常尽力保存。SIGKILL、断电或崩溃可能导致本轮没有完整
归档；系统不会因此重新执行模型或工具。记录失败与业务执行、授权、投递结果独立。

## Harness 使用

在 AI Harness 页面加载已完成的 run 或 Case 实例。完整归档在启动时校验并复制对应索引和全部
正文；机器人归档不可用时，冻结现有观测及证据缺口，点击「开始修复」仍会进入诊断。冻结来源不依赖原实例或测评的保留期限。修复工具只能读取受控的证据目录；正文、
用户反馈、根因假设、判分预期和验证结果仍具有不同职责。原始成绩不改写。

没有归档的旧 Case 仍只供导出查看。机器人旧观测可用于新修复诊断，但不能补造上下文或冒充完整归档。
旧受阻任务可点「重新发起修复」带入已填写内容。

归档失败时，详情显示具体错误类型和原因。遇到「运行环境缺少 DeepEval」，通过既有实例
更新入口同步锁定依赖；安装器会在实例 Python 中实际保存和读取一份临时归档，失败则停止更新。
升级使用既有实例更新与 Evaluation/Harness 维护窗口；依赖由 agent/evaluation 安装分组
声明。新格式使用独立目录，代码回滚不删除新旧文件。具体规格见
[本地 DeepEval tracing](runtime.md)。
