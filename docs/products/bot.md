# AgentStrata Bot · QQ 助手

基于 AgentStrata 构建的消息机器人应用。用户在 Studio 中描述用途、确认配置、连接平台并启动自己的实例；每个实例仍可以使用自定义名称。

## 从这里开始

- QQ 官方机器人：[Studio 创建指南](../guides/desktop-studio.md#创建-qq-官方机器人)。使用平台机器人凭据，按平台允许的范围试聊。
- 已有 NapCat / OneBot 接入：[独立技术指南](../guides/qq.md)。这与 QQ 官方机器人不是同一种登录、权限或交付路径。
- 配置与运行机制：[运行时参考](../reference/runtime.md)。

当前官方 QQ 路径是源码 MVP。已配置、进程运行和平台连接不代表真实消息已完成往返，必须在目标账号及模型条件下验收。不提供独立公开安装包或云托管服务。

产品名用于展示，qq_official、qq_onebot 等渠道标识保持不变；产品实例名称不应被品牌更新覆盖。
