# AgentStrata Bot · QQ 助手

QQ 助手可以使用官方机器人账号，也可以通过 NapCat 接入 QQ 账号。聊天发生在 QQ，工作台负责配置、运行状态和任务记录。

## 从这里开始

| 你手上有什么 | 使用入口 |
| --- | --- |
| QQ 官方平台的 AppID 和 AppSecret | 从「我的应用 → 创建应用」说明用途，确认官方机器人方案，在「渠道与工具」保存凭据，再到「运行状态」检查并启动。[创建官方机器人](../guides/desktop-studio.md#创建-qq-官方机器人) |
| 用于登录 NapCat 的 QQ 账号 | 新实例使用 Linux/WSL2 的[首次部署向导](../guides/deployment.md)。已有实例从「运行状态」打开 NapCat 管理页并检查登录。[QQ 与 NapCat 运维](../guides/qq.md#qq--napcat) |

用目标账号私聊或在适用的群中 @ 机器人，确认 QQ 客户端收到回复。「应用试聊」仅在 Studio 创建的官方 QQ 应用中提供，回复显示在工作台。给其他电脑安装时，先核对应用「下载与部署」列出的渠道、模型和运行要求。[安装与使用](../guides/desktop-studio.md#把应用交给另一台电脑)

每个实例可以使用自己的名称。展示名称不改变已有的渠道配置和身份。[渠道运行机制](../reference/runtime.md)
