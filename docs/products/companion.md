# AgentStrata Companion · 桌面伙伴

基于 AgentStrata 构建的桌面角色应用：用文字和语音对话，并在已配置的权限范围内使用工具。Live2D 是角色呈现技术，底层插件是应用组件，不是产品本身。

## 从这里开始

- 使用和平台要求：[Live2D 指南](../guides/live2d.md#windows-桌面客户端)。
- 源码构建：[桌面项目 README](../../integrations/live2d_desktop/README.md)。
- 在工作台连接并改进应用：[Studio 指南](../guides/desktop-studio.md#开发桌面应用与已有-live2d)。

当前以源码预览提供，构建产物不等于已经公开发布的安装包。安装器保留原名称 AgentStrata Live2D Native；用户数据路径、包名和技术 ID 不因展示名改变而迁移。

“异世界情绪”是演示角色名称，不是产品名或通用默认身份。角色、声音、Live2D SDK 和 Open-LLM-VTuber 等素材与依赖继续遵守各自许可；产品命名不改变授权或署名要求。
