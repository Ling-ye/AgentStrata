# 独立微信实例

此实例复用 QQ 实例的 Agent、工具及集中模型用途引用，但拥有独立工作区和 Gateway 状态。
使用本人现有微信扫码，无需另注册普通微信号。

1. 在 Console 中配置实例所需的模型用途、Codex 可执行文件和独立认证根，以及获准项目路径。
2. 在实例的「分层配置 → Channel」打开微信条目，停止实例后点击「扫码绑定微信」。
3. 使用本人微信扫描二维码并确认；需要验证码时在 Console 输入微信显示的值。
4. 绑定完成后通过原有实例启动入口启动，再在微信 ClawBot 会话中发送消息。

凭据和 Owner 身份保存到被忽略的 `local.env`。本人单聊才进入 Gateway；群消息和其他
发送者不会执行 Agent。重新绑定不同账号必须新建实例，不迁移原有工作区。

文本、图片和文件通过项目原有权限与资源流程处理。平台提交确认与用户实际收到分别判断；
发送未知时不会自动重发。首次使用需要实际扫码和消息往返验收，代码检查不能代替微信验证。
