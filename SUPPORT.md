# Support

Use [GitHub Issues](https://github.com/Ling-ye/AgentStrata/issues) for
reproducible bugs, focused feature proposals, and usage questions. Search open
and closed issues first, then use the matching issue form and provide a minimal
reproduction, operating system, Python version, and redacted logs.

For setup and operation, start with the [documentation map](docs/README.md),
[Harness guide](docs/guides/harness.md), or [Evaluation guide](docs/guides/evaluation.md).
The main usage documentation is in Chinese.

For Harness or evaluation issues, include the source type, failing stage,
expected and observed behavior, model profile configuration without secrets,
and the smallest redacted check result that reproduces the problem. Distinguish
repair, evaluation, and delivery status, and say whether external services were
real or fixtures. Keep private task IDs, raw evidence archives, and credentials
out of public reports; use synthetic identifiers where needed.

This community project has no guaranteed response time, service-level
agreement, or private consulting channel. The maintainer email is reserved for
Code of Conduct enforcement and security coordination, not troubleshooting.

Do not include credentials, tenant URLs, account or group IDs, private project
names, machine paths, or unredacted logs in an issue. Report vulnerabilities
through the private process in [SECURITY.md](SECURITY.md).
